## How to ship a release
1. Bump `chesspuz.__version__` and `pyproject.toml`; tests + ruff; commit.
2. Windows zip, from PowerShell: `$env:PATH = "$PWD\.venv\Scripts;$env:PATH"; .\build_release.bat` (the PATH python is 3.12 without chess; Git Bash `cmd //c` cannot find the bat). Output `dist\chesspuz-X.Y.Z-windows.zip`. Smoke: run `dist\chesspuz\chesspuz.exe` offscreen for about 12 s with `CHESSPUZ_DATA_DIR` pointing at a scratch dir; a `user.sqlite` appearing there means the bundle started.
3. APK: `.venv\Scripts\python.exe android\sync.py sync build --version X.Y.Z` (about a minute; works from Bash too). Commit first, or the build stamp (`android/app/mobile/build_info.py`, printed at startup in logcat) shows "+". `python android\sync.py install run` only with the phone on USB.
4. Screenshots if the UI changed: `python tools\release_shots.py docs\screenshots desktop` and `... phone`, look at them (the Read tool shows PNGs), commit.
5. Notes in `build\release-notes-X.Y.Z.md` (copy the previous page: `gh release view vPREV --json body -q .body`; hero image, download table, "New in", every feature with an image, phone trio, support link; images as `https://raw.githubusercontent.com/CARTER-BNW/chesspuz/main/docs/screenshots/...`; no em dashes). `git push` first (the images must be on main), then `gh release create vX.Y.Z --draft --target main --title "chesspuz X.Y.Z" --notes-file build\release-notes-X.Y.Z.md dist\...zip android\bin\...apk` with absolute paths; `--draft=false` on `gh release edit` publishes after the phone check.
6. README PDF: `python <scratch>\readme_pdf_source.py X.Y.Z "D Month YYYY"` is the transformation (this session's scratch script; the rules: a "Version X.Y.Z, date. Downloads: [..](..)" line under the H1, relative links made absolute to github.com/CARTER-BNW/chesspuz/blob/main/..., every bare URL as an explicit `[text](url)` link, the HTML `<img>` blocks turned into `![..](docs/screenshots/..){width=full}` / `{width=45%}`, the "Created ... template" line replaced by a source link plus a "More screenshots" section with review, leaderboard and stats; screenshots copied to `build\docs\screenshots`). Then from Git Bash in `build\`: `GSTACK_BROWSE_BIN="D:\\Claude\\config\\skills\\gstack\\browse\\dist\\browse" D:/Claude/config/skills/gstack/make-pdf/dist/pdf.exe generate --cover --no-confidential --author "John Carter" --title "chesspuz X.Y.Z" --date "..." README-X.Y.Z.md chesspuz-X.Y.Z-readme.pdf` (3 s; no `--toc`, its page numbers come out empty). Check the pages with PyMuPDF from the system Python 3.12 (`python -m pip install --target <scratch>\pymupdf pymupdf`, then `PYTHONPATH=<scratch>\pymupdf python` renders `page.get_pixmap()` to PNG). `gh release upload vX.Y.Z build\chesspuz-X.Y.Z-readme.pdf`.
7. Rewrite this file, tick docs/PLAN.md, commit, push.
