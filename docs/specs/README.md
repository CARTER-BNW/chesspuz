# Specs

One markdown file per feature, written before building anything bigger than a small fix.

- File name: `<feature>.md` (kebab-case)
- Sections: Goal - Out of scope - Files and interfaces involved - Edge cases - Verification (how we prove it works end to end)
- Ask Claude to interview you first: "I want to build X. Interview me with AskUserQuestion, then write docs/specs/x.md"
